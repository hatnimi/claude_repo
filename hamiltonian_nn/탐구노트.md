## 3. 수학 정리 (내 말로 다시 쓰기)

### 3-1. 해밀턴 경로 층
$$y = (D_a + D_b S)P_\pi x + c \quad \text{(순서를 바꾼 이중대각 행렬)}$$

### 3-2. 역전파 (직접 유도)
- $\partial L/\partial a_k = \sum g_k u_k$, $\partial L/\partial b_k = \sum g_k v_k$, $\partial L/\partial c_k = \sum g_k$
- $u_k$는 $y_k$와 $y_{k-1}$ 두 곳에 쓰이므로 $\partial L/\partial u_k = a_k g_k + b_{k-1}g_{k-1}$
- $\partial L/\partial x = P_\pi^\top\, \partial L/\partial u$ (역순열로 되돌리기)
- 검증: gradcheck( ), 자동미분과 차이( ), 야코비안 = W ( )

### 3-3. 라플라시안
- $L = D - A$. 고윳값 0의 개수 = 연결 성분 수. $\lambda_2 > 0$ ⇔ 연결.
- 해밀턴 경로 층은 정점 $2n$개짜리 경로 그래프 $P_{2n}$이므로 고윳값이 $2 - 2\cos\frac{k\pi}{2n}$. 노트북에서 수치 계산과 일치하는지 확인 ( )
- 정점 $2n$개를 연결하려면 간선이 최소 $2n-1$개(신장 트리). **해밀턴 경로 = 최대 차수가 2인 신장 트리** → 최소 간선으로 연결 + 모든 뉴런이 고르게 쓰임.

### 3-4. 이중확률행렬, 최적 운송, 싱크혼
- **버코프 정리**: 이중확률행렬 = 순열행렬들의 볼록 결합. 꼭짓점이 순열행렬. (노트북 5-5에서 실제로 분해해 봄: 순열 ( )개)
- **싱크혼 정리**: 양수 행렬 $A$에 대해 $D_1AD_2$가 이중확률이 되는 양의 대각행렬이 있고, 행·열 정규화 반복으로 구할 수 있다.
- **엔트로피 정규화 최적 운송**: $\min \langle C,P\rangle - \varepsilon H(P)$의 해가 $P = \mathrm{diag}(u)e^{-C/\varepsilon}\mathrm{diag}(v)$ (라그랑주 승수로 유도). $\varepsilon \to 0$이면 순열(선형 할당 문제의 해).
- **싱크혼 역전파 (직접 유도)**: 로그 영역 행 정규화 $\ell' = \ell - \mathrm{LSE}(\ell)$의 역전파는 $\partial L/\partial \ell = G - Q\odot(\textstyle\sum_j G)$. 소프트맥스의 야코비안과 같은 꼴이다.

## 6. 한계와 후속 탐구
- 층을 깊게 쌓으면 성능이 오히려 떨어질 수 있다 → 잔차 연결, 정규화, 초기화 개선
- 해밀턴 경로 학습은 국소 최솟값에 잘 빠진다 → 여러 번 시작(restart), Gumbel 노이즈, 경로를 직접 탐색하는 방법
- 진짜 속도 이득을 얻으려면 Triton/CUDA로 연산 전체를 커널 하나로 합친 전용 커널이 필요하다
- 찾아보니 비슷한 방향의 연구가 있다:
  - 구조적 희소 행렬로 밀집층 대체: Butterfly 행렬(Dao 외, ICML 2019), Monarch 행렬(Dao 외, ICML 2022)
  - 그래프 이론으로 희소 연결 설계: Deep Expander Networks(Prabhu 외, ECCV 2018)
  - 싱크혼으로 순열 학습: Gumbel-Sinkhorn(Mena 외, ICLR 2018), 싱크혼 거리(Cuturi, NeurIPS 2013)

## 7. 면접 예상 질문과 답변 방향

**Q1. 왜 해밀턴 경로를 신경망에 적용했나요?**
신경망의 층을 정점과 간선의 그래프로 보면, 밀집층은 모든 정점을 잇는 완전 이분 그래프입니다. 모든 뉴런을 빠짐없이 쓰면서 연결은 최소로 하는 구조가 무엇일까 생각했는데, 모든 정점을 한 번씩만 지나는 해밀턴 경로가 그 조건에 맞았습니다.

**Q2. 그 층을 수식으로 설명해 보세요.**
$y_k = a_k x_{\pi(k)} + b_k x_{\pi(k+1)} + c_k$. 이분 그래프의 해밀턴 경로는 입력과 출력을 번갈아 지나므로 출력 하나가 이웃한 입력 두 개와만 이어집니다. 행렬로는 순서를 바꾼 이중대각 행렬입니다.

**Q3. 간선 수만 같게 무작위로 연결하는 것과 뭐가 다른가요?**
라플라시안 행렬의 고윳값으로 비교했습니다. 무작위 연결은 연결 성분이 ( )개로 쪼개지고 고립된 뉴런이 ( )개 생겼지만, 해밀턴 경로는 $\lambda_2 > 0$으로 하나로 연결되어 있습니다. 정점 $2n$개를 연결하는 최소 간선 수가 $2n-1$이므로, 해밀턴 경로는 최소 간선으로 연결을 보장하는 구조입니다. 정확도도 ( )였습니다.

**Q4. 역전파를 직접 유도했다는데, 맞는지 어떻게 확인했나요?**
세 가지로 확인했습니다. (1) 중앙차분 $\frac{f(\theta+\varepsilon)-f(\theta-\varepsilon)}{2\varepsilon}$으로 구한 수치 미분과 비교하는 gradcheck, (2) PyTorch 자동미분 결과와 비교, (3) 야코비안을 직접 계산해 가중치 행렬 $W$와 같은지. 그리고 실제 학습도 제가 유도한 식으로 돌렸습니다.

**Q5. 야코비안은 어디에 썼나요?**
역전파는 결국 $J^\top g$를 계산하는 것이라 야코비안의 구조(행마다 0이 아닌 값 2개)가 곧 역전파 비용 $O(n)$을 결정합니다. 또 층을 쌓으면 전체 야코비안의 0이 아닌 칸이 $2^L$씩 퍼진다는 것을 보고, 모든 입력이 섞이려면 $\log_2 n$층이 필요하다는 것을 알았습니다.

**Q6. 이중확률행렬과 싱크혼은 왜 필요했나요?**
순열은 $n!$개 중 하나를 고르는 이산 선택이라 미분할 수 없습니다. 버코프 정리에 따르면 이중확률행렬의 집합은 순열행렬을 꼭짓점으로 하는 볼록 다면체이므로, 다면체 안에서 연속적으로 학습하다가 마지막에 꼭짓점(순열)으로 내려앉힐 수 있습니다. 싱크혼 알고리즘이 임의의 점수 행렬을 이중확률행렬로 바꿔 주고, 온도를 낮추면 순열에 가까워집니다.

**Q7. 최적 운송 이론과는 어떤 관계인가요?**
엔트로피 항을 더한 최적 운송 문제를 라그랑주 승수로 풀면 해가 $\mathrm{diag}(u)e^{-C/\varepsilon}\mathrm{diag}(v)$ 꼴이 되는데, 이것이 싱크혼 정리의 $D_1AD_2$와 같은 모양입니다. 점수 행렬을 비용의 음수로 보면 '입력 뉴런을 출력 위치로 옮기는 운송 계획'을 학습하는 셈입니다.

**Q8. 경로 학습은 잘 됐나요?**
(결과에 따라) 순열 하나만 맞히는 문제는 ( )% 복원했지만, 해밀턴 경로는 ( )%에 그쳤습니다. 이웃한 두 출력이 같은 입력을 공유해서 국소 최솟값이 생기기 때문이라고 생각합니다. 해밀턴 경로 찾기가 외판원 문제처럼 어려운 문제라는 것과 연결됩니다.

**Q9. 이론상 수백 배 빨라야 하는데 실제로는요?**
$n=$( )에서 FLOP 비는 ( )배였지만 실제 가속은 ( )배였습니다. 밀집 행렬곱은 데이터 하나를 읽어 여러 번 계산하므로(산술 강도가 높음) GPU 연산 장치를 꽉 채워 쓰지만, 해밀턴 층은 읽은 값으로 한두 번만 계산하고 버려서 메모리 대역폭이 병목입니다. 또 작은 연산 여러 개라 커널을 ( )번 띄우는데, $n$이 작을 때는 이 비용이 계산보다 큽니다. 커널을 하나로 합쳤더니 ( )배가 되었습니다. 연산량이 줄어도 하드웨어가 그 구조를 잘 활용하지 못하면 시간은 줄지 않는다는 것을 배웠습니다.

**Q10. 그러면 이 구조는 쓸모가 있나요?**
파라미터가 약 1%라 메모리가 매우 적게 들고, $n$이 클수록, 그리고 CPU처럼 병렬성이 낮은 환경일수록 이득이 큽니다. 다만 정확도 손실이 있고, 진짜 속도 이득을 얻으려면 전용 커널이 필요합니다. 비슷한 생각으로 Butterfly나 Monarch 같은 구조적 희소 행렬 연구가 있다는 것을 찾아보았습니다.
